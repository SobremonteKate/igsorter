      How it works
      

        Collection is passive: the content script only reports tiles your browser has
        already rendered. Classification sends each thumbnail to the DeepSeek vision
        model. Write-back opens one background tab per post, clicks the bookmark and
        the collection checkbox using a logged-in session — your password is never
        read, stored or sent.
